# Meridian Bank: Data Protection Standard

**Version 3.4 · Status: CURRENT · Effective 1 February 2026 · Owner: Data Protection Officer**

## 1. Collection and use

**1.1** The bank collects only the personal data it needs for a stated purpose.

**1.2** Data is not used for a new purpose without a documented assessment.

## 2. Retention

**2.1** Personal data is deleted when the retention period in the retention schedule ends.

## 3. Location of data

**3.1** Customer data is stored inside the country unless the Data Protection Officer **approves another location in writing**.

## 4. Requests from customers

**4.1** The bank answers a customer's request for their data within thirty days.
